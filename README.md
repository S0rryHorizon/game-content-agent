# 雾潮群岛 · 任务策划与审核 Agent

一个本地、单用户的任务设计 Demo：确认需求，生成带分支的任务草稿，查看规则检查与版本差异，由人审核后导出。审核和导出不会改变玩家状态。

默认运行 **离线脚本演示**，无需账号或 API 密钥。生成内容来自明确标注的预设样例；HTTP 接口、SQLite、工具调用、规则校验、版本审核及导出实际运行。真实模型适配器已实现，但真实生成和自然语言修订的效果尚未验收。

## 运行

使用 Python 3.12 和 uv：

```sh
git clone https://github.com/S0rryHorizon/game-content-agent.git
cd game-content-agent
uv sync --locked --python 3.12
uv run uvicorn game_content_agent.web.app:create_app --factory --app-dir src --host 127.0.0.1 --port 8765
```

打开 http://127.0.0.1:8765 。macOS 安装依赖后也可双击 `启动演示.command`。服务只在本机前台运行；按 Control-C 停止。端口被占用时选择另一个端口，不要关闭不明服务。

运行数据库、费用账本、缓存和回放写入被 Git 忽略的 `data/runtime/`。同一个数据库只允许一个进程运行；不要为启动第二个实例而删除数据库或锁文件。

## 演示流程

1. 使用页面示例：“围绕米拉和北潮门，设计一个有分支的支线任务”，整理并确认需求。
2. 生成任务，查看分支图、静态检查和工具轨迹。
3. 使用示例修订：“保留结局，把第二个分支改成帮助米拉”，比较版本和差异。
4. 填写审核理由，接受具体版本，导出 JSON 或设计报告。
5. 新建会话，选择冲突或错误场景，观察系统暂停并要求人工选择。

离线模式仅支持预设的正常、修订、冲突与错误场景。任意自由输入不会被包装成真实模型生成。

## 结构与边界

- FastAPI 和中文网页提供入口、任务图、差异、审核与导出。
- Pydantic 约束输入和领域对象；SQLite 保存版本与审核，当前持久化实现使用 `sqlite3`。
- Runtime 驱动受限工具调用；Gateway 区分 Fake 与真实模型适配器。
- 确定性规则检查角色、地点、引用与图结构；结构可达不等于游戏内动态可完成。
- 审核绑定版本与内容摘要，在事务内复核；陈旧页面不能接受已变化的候选。
- 六步上限、有限格式修复、超时及费用预留限制运行；未知结果不会自动重放。

```text
确认需求 → 读取状态 / 检索设定 → 生成与规则校验
        → 保存候选版本 → 人工审核 → 导出已接受版本
```

## 数据与发布范围

`data/world/`、`data/examples/`、`data/scenarios/` 是用于演示和测试的合成内容。公开仓库只包含源码、测试、这些静态数据及运行配置/说明，不包含原开发仓库的私人历史、学习计划、真实会话、数据库、日志、缓存或密钥。

`.env.example` 只有空密钥和配置示例；`.env`、`data/runtime/`、数据库文件及常见私钥文件被忽略。本地开发统一使用这个仓库；内部资料和旧历史恢复包集中存放在被忽略的 `private/`，运行数据仍在 `data/runtime/`，密钥只放 `.env`。虚拟环境和缓存同样不提交。具体规则见 `.gitignore`；不要用 `git add -f` 绕过这些规则。公开 CI 另检查文件白名单，拒绝跟踪私人资料和数据库。

请勿用真实数据替换合成 fixture 后提交。源码与测试开发使用了 AI 辅助；公开代码和 CI 不代表作者独立编写了全部实现，也不代表已完成真实模型效果验收。

## 可选真实模型

离线演示无需配置。需要真实调用时，在本机复制 `.env.example` 为 `.env`，自行填写可用模型、embedding 模型、密钥、已核验价格与日期后显式启用 `LIVE_API_ENABLED`。不提供预填密钥或价格；配置不足时 Live 不可用。

账本只统计本应用经适配器发起的调用，不是账户余额。当前预算上限 S$10、预警 S$8，超时或缺失用量时保留预留。真实模型输出、剧情语义和约束满足仍须独立验证；本项目不是已部署的多用户平台。
